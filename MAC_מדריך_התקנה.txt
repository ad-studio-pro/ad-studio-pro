============================================================
              Ad Studio Pro — התקנה ב-Mac
============================================================

הבעיה: macOS Gatekeeper זורק קבצי .command unsigned לזבל.
זה לא תלוי בקוד שלנו — זה תכונת אבטחה של אפל.

------------------------------------------------------------
פתרון מהיר (פעם אחת בלבד) — דרך Terminal
------------------------------------------------------------

1. פתח Terminal
   (Command+Space → הקלד "Terminal" → Enter)

2. עבור לתיקיית הפרויקט:
   cd ~/Documents/ad-studio-pro
   (או איפה שחילצת אותה)

3. הרץ את התיקון:
   bash FIX_MAC_PERMISSIONS.sh

4. סיימת! עכשיו אתה יכול לעשות קליק כפול על:
   1_SETUP.command
   START_CHROME.command
   APP_START.command

------------------------------------------------------------
פתרון חלופי — שחרור ידני של הקובץ
------------------------------------------------------------

אם הקובץ עוד לא בזבל:
1. לחץ קליק ימני על  1_SETUP.command
2. בחר Open (לא Double-click!)
3. אם macOS מתריע — אשר "Open"
4. חזור על אותו דבר עם השאר

אם macOS השלך לזבל כבר:
1. הוצא מהזבל (קליק ימני → Put Back או גרור החוצה)
2. השתמש בפתרון העיקרי למעלה

------------------------------------------------------------
פתרון 3 — System Settings (macOS Sequoia/Sonoma)
------------------------------------------------------------

בגרסאות מ-Sequoia ומעלה Apple חוסם יותר אגרסיבי:

1. נסה לפתוח את הקובץ → macOS יזרוק שגיאה
2. פתח System Settings → Privacy & Security
3. גלול למטה — תראה "FILE was blocked"
4. לחץ "Open Anyway"
5. אשר עם סיסמת המחשב

------------------------------------------------------------
דרישות בסיסיות
------------------------------------------------------------

- macOS 12+ (Monterey)
- Python 3.10+ — אם אין:
  brew install python   (אם יש brew)
  או הורד מ-https://www.python.org/downloads/macos/
- Google Chrome
- חשבון Claude.ai (Pro/Max עדיף — לגישה ל-Opus 4.7)

------------------------------------------------------------
אחרי שזה רץ — סדר הקליקים זהה ל-Windows:
------------------------------------------------------------

1. 1_SETUP.command          (פעם אחת לחיים)
2. START_CHROME.command     (פעם אחת בכל הדלקה)
3. APP_START.command        (בכל פעם שרוצים לעבוד)
