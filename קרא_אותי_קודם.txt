מה זה?
מערכת ליצירת פרסומות וידאו אוטומטיות לכל מוצר:
טבעות, אבקות, גאדג'טים, מוצרי טיפוח, מזון, ביגוד, וכו'.

   בריף → Claude כותב פרומטים → BytePlus יוצר וידאו

------------------------------------------------------------
לפני הכל — חובה (פעם אחת):
------------------------------------------------------------

Python 3.10+ מותקן
- Windows: https://www.python.org/downloads/, סמן "Add Python to PATH"
- Mac: 'brew install python' או הורדה מ-python.org

המפתחות ב-.env (כבר שמורים):
  ARK_API_KEY     — BytePlus Seedance 2.0
  IMGBB_API_KEY   — אחסון תמונות
  CDP_PORT=9224   — פורט Chrome

------------------------------------------------------------
סדר הקליקים — שלוש פעולות:
------------------------------------------------------------

  שלב 1 (פעם אחת):
  Windows: 1_SETUP.bat
  Mac:     1_SETUP.command

  שלב 2 (פעם אחת בכל הדלקה):
  Windows: START_CHROME.bat
  Mac:     START_CHROME.command
  בפעם הראשונה: תתחבר ל-claude.ai, בחר Opus 4.7.
  השאר Chrome פתוח.

  שלב 3 (כל פעם שאתה רוצה לעבוד):
  Windows: APP_START.bat
  Mac:     APP_START.command
  
  באפליקציה:
  1. בריף + תיאור המוצר + שם מותג
  2. תמונות מוצר
  3. הגדרות (יחס, משך, איכות)
  4. "צור פרומטים"
  5. "צור וידאו" (אחד או הכל)

מה החדש לעומת thunderfit-ads?
------------------------------------------------------------

אותו mechanism — אבל ללא חוקים ספציפיים-לטבעת.
עכשיו זה עובד לכל מוצר.

מה השתנה ב-system prompt של Claude:
✓ "PRODUCT CONSISTENCY" כללי (במקום "ONE RING ONE FINGER")
✓ "NO OTHER PRODUCT INSTANCES" כללי
✓ ברירת מחדל ריקה לתיאור מוצר ולמותג
